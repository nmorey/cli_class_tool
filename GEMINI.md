# Project Instructions

This file contains foundational workspace rules and mandates.

## Commit Guidelines

- **Rake Task Verification**: Run `rake` (with no extra arguments) to verify the build and tests before making any commit.
- **Changelog Updates**: The `CHANGELOG` must be populated before committing.
  - Do not add any release/version tags, as versioning and tagging are handled automatically by another script.
  - Only add changelog entries to the top list (or create one if it is missing).

## Documentation

- **Feature & API Changes**: Document all new features and API changes in the `README.md` file.
